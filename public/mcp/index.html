MCP /agents IA

Piloter Binksy ClearSpace sans cliquer : window.BinksyAPI dans l'app, outils WebMCP, et connexion des agents de code via Playwright MCP. Rien n'est envoyé.

FrançaisEnglishAGENTS.mdllms.txt

Un agent IA (agent du navigateur, Claude Code, Codex, Hermes, OpenCode…) peut piloter Binksy ClearSpace sans cliquer dans l'interface, grâce à l'objet window.BinksyAPI présent dans la page et, quand le navigateur le permet, aux outils WebMCP. Tout se passe dans l'onglet : chaque appel utilise les mêmes fonctions que l'interface, met l'écran à jour et déclenche l'enregistrement automatique.

1. Ce que l'agent peut faire

Outil WebMCPMéthodeRôle
clearspace_describeBinksyAPI.describe()Décrit l'app et liste les outils (schémas JSON).
clearspace_etatBinksyAPI.getState()État : variantes, réglage de zone de chacune (méthode, ×, X, zone), aperçu, thème.
clearspace_importerBinksyAPI.importer()Importe des SVG (une variante par fichier).
clearspace_exporterBinksyAPI.exporter()Exporte le ZIP complet ou une planche SVG/PNG/JPEG/PDF claire ou foncée (base64).
clearspace_definir_zoneBinksyAPI.setClearSpace()X = hauteur, largeur ou mesure visuelle ; zone = X × multiplicateur.
clearspace_choisir_varianteBinksyAPI.setActive()Affiche une variante dans l'aperçu.
clearspace_renommer_varianteBinksyAPI.renameVariant()Renomme une variante (nom des dossiers et fichiers).
clearspace_supprimer_varianteBinksyAPI.removeVariant()Supprime une variante (après accord de l'utilisateur).
clearspace_affichageBinksyAPI.setDisplay()Fond d'aperçu clair/sombre et thème de l'interface.
clearspace_resetBinksyAPI.reset()Vide le projet (confirm:true, après accord de l'utilisateur).

Méthodes communes : describe(), ready(), getState(), importer(), exporter(), reset(). Toutes sont asynchrones et renvoient du JSON ; une erreur est rejetée sous la forme { code, message }. BinksyAPI.callTool(nom, args) appelle un outil par son nom WebMCP.

2. Connexion A — agent dans le navigateur (WebMCP)

WebMCP est une proposition du W3C (Web Machine Learning) encore expérimentale. Dans une version récente de Chrome qui la propose, active-la depuis chrome://flags (cherche « WebMCP ») ou utilise une extension compatible WebMCP, puis ouvre l'app : les outils ci-dessus sont déclarés automatiquement (document.modelContext.registerTool, ou navigator.modelContext selon la version). Si le navigateur ne connaît pas WebMCP, rien ne change : window.BinksyAPI reste disponible.

3. Connexion B — Claude Code, Codex, Hermes, OpenCode (Playwright MCP)

Ajoute le serveur MCP navigateur standard Playwright MCP à la configuration de ton agent :

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}

Ensuite l'agent ouvre https://clearspace.binksdesign.com/app.html (outil browser_navigate), puis appelle window.BinksyAPI avec l'outil browser_evaluate. Exemples :

// outil browser_evaluate
await BinksyAPI.ready();
const d = await BinksyAPI.describe();   // { app, apiVersion: "1", tools: [...] }
const s = await BinksyAPI.getState();  // s.variants[].id, .clearSpace
const r = await BinksyAPI.importer({
  files: [{ name: 'marque-horizontal.svg', type: 'image/svg+xml', dataBase64: '<BASE64_DU_SVG>' }]
});
const id = r.imported[0].id;
await BinksyAPI.setClearSpace({ variantId: id, method: 'height', multiplier: 0.5 });
const zip = await BinksyAPI.exporter({ format: 'zip' });
// zip.files[0] = { name: 'sans-titre-clearspace.zip', type: 'application/zip', dataBase64: '…' }
const png = await BinksyAPI.exporter({ format: 'png', variantId: id, tone: 'fonce' });

4. Prompt prêt à copier

Ouvre https://clearspace.binksdesign.com/app.html avec le navigateur (Playwright MCP). Attends await window.BinksyAPI.ready(), puis lis await BinksyAPI.describe(). Importe mes SVG avec BinksyAPI.importer (les fichiers que je te donne, en base64), applique pour chaque variante la règle de zone de sécurité que je t'indique avec BinksyAPI.setClearSpace, vérifie avec BinksyAPI.getState(), puis exporte avec BinksyAPI.exporter({ format: 'zip' }) et enregistre le ZIP renvoyé (base64). Ne modifie ni ne redessine jamais mes logos et n'invente aucune règle.

5. Rien n'est envoyé

Pas de compte, pas de clé API, pas de serveur : Binksy ClearSpace calcule tout dans le navigateur et garde ton travail sur ton appareil (enregistrement local). L'API ne fait aucun appel réseau, ne lit aucune clé et ne crée jamais de logo, de couleur ou de nom client : elle manipule seulement ce que le graphiste fournit.

AI agents can drive Binksy ClearSpace without clicking: the page exposes window.BinksyAPI and, when the browser supports it, WebMCP tools. Everything runs in the tab, through the same functions as the UI (the screen updates and auto-save runs).

Tools

WebMCP toolMethodWhat it does
clearspace_describeBinksyAPI.describe()Describes the app and lists tools (JSON schemas).
clearspace_etatBinksyAPI.getState()State: variants, each clear-space setting (method, ×, X, space), preview, theme.
clearspace_importerBinksyAPI.importer()Imports SVGs (one variant per file).
clearspace_exporterBinksyAPI.exporter()Exports the full ZIP or one SVG/PNG/JPEG/PDF board, light or dark (base64).
clearspace_definir_zoneBinksyAPI.setClearSpace()X = height, width or visual measure; space = X × multiplier.
clearspace_choisir_varianteBinksyAPI.setActive()Shows a variant in the preview.
clearspace_renommer_varianteBinksyAPI.renameVariant()Renames a variant (folder and file names).
clearspace_supprimer_varianteBinksyAPI.removeVariant()Removes a variant (after user consent).
clearspace_affichageBinksyAPI.setDisplay()Light/dark preview background and UI theme.
clearspace_resetBinksyAPI.reset()Clears the project (confirm:true, after user consent).

Connect

  • A — in-browser agent (WebMCP, experimental): in a recent Chrome that offers it, enable WebMCP in chrome://flags or use a WebMCP-compatible extension, then open the app; tools register automatically.
  • B — Claude Code / Codex / Hermes / OpenCode: add Playwright MCP (npx @playwright/mcp@latest, config above), open https://clearspace.binksdesign.com/app.html and call window.BinksyAPI with browser_evaluate (examples above).
